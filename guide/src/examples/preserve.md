# การรักษาทูลเชนไว้

คุณอาจต้องการนำทูลเชนที่ `cargo-bisect-rustc` ดาวน์โหลดมาใช้ซ้ำ เพื่อวิเคราะห์หรือดีบักเพิ่มเติม
หรือในขณะที่กำลังเตรียมการทดสอบรีเกรสชันของคุณ คุณอาจต้องปรับการทดสอบและสคริปต์หลายครั้ง และการดาวน์โหลดทูลเชนเดิมซ้ำหลาย ๆ ครั้งอาจช้ามาก

คุณสามารถทำได้ด้วยตัวเลือก `--preserve`

```sh
cargo bisect-rustc --start=2023-01-01 --end=2023-02-01 --preserve
```

ทูลเชนจะถูกเก็บไว้ในโฮมไดเรกทอรีของ Rustup ของคุณ (โดยทั่วไปคือ `~/.rustup/toolchains`)

ทูลเชนสำหรับ nightly จะมีรูปแบบ `bisector-nightly-YYYY-MM-DD-<target>`
ทูลเชนสำหรับอาร์ติแฟกต์ PR จะมีรูปแบบ `bisector-ci-<hash>-<target>`

คุณสามารถรันทูลเชนเหล่านี้ได้โดยใช้การโอเวอร์ไรด์ของ Rustup เช่นนี้:

```sh
cargo +bisector-nightly-2023-03-18-x86_64-unknown-linux-gnu build
# or...
cargo +bisector-ci-e187f8871e3d553181c9d2d4ac111197a139ca0d-x86_64-unknown-linux-gnu build
```

เมื่อเสร็จแล้ว คุณอาจต้องการล้างไดเรกทอรีเหล่านี้ เพราะมันกินพื้นที่มาก
วิธีที่ง่ายที่สุดคือลบไดเรกทอรีเหล่านั้นทิ้ง:

```sh
rm -rf ~/.rustup/toolchains/bisector-*
```

## การติดตั้งด้วยตนเอง

ตัวเลือก `--install` ใช้ติดตั้งเฉพาะทูลเชนได้
ตัวเลือกนี้จะไม่ทำการไบเซกต์ เป็นเพียงการดึงทูลเชนมาเพื่อทดสอบเท่านั้น

```sh
cargo bisect-rustc --install e187f8871e3d553181c9d2d4ac111197a139ca0d
```

> **หมายเหตุ**: ดูเพิ่มเติมได้ที่ [`rustup-toolchain-install-master`](https://github.com/kennytm/rustup-toolchain-install-master) ซึ่งเชี่ยวชาญด้านการติดตั้งอาร์ติแฟกต์ CI
