# การรันโดยไม่ใช้ Cargo

การไบเซกต์บางอย่างไม่จำเป็นต้องใช้ Cargo
คุณสามารถใช้ตัวเลือก `--without-cargo` เพื่อข้ามการติดตั้ง cargo ซึ่งช่วยให้การไบเซกต์เร็วขึ้น เพราะไม่ต้องดาวน์โหลด cargo และไม่มีค่าใช้จ่ายในการรัน cargo
คุณจะต้องจับคู่ตัวเลือกนี้กับ `--script` เพราะ `cargo-bisect-rustc` ถือว่าโปรเจกต์ใช้ Cargo

ตัวอย่างเช่น การใช้คำสั่ง `rustc` ง่าย ๆ:

```sh
cargo-bisect-rustc --start=2022-11-01 --end=2022-11-20 --without-cargo --script=rustc -- foo.rs
```

> **หมายเหตุ**: คุณสามารถใช้ `--without-cargo` พร้อมกับยังใช้โปรเจกต์ Cargo ได้
> Rustup จะถอยไปใช้ `cargo` จากทูลเชน nightly, beta หรือ stable ที่ติดตั้งไว้
> อย่างไรก็ตาม วิธีนี้ไม่แนะนำ เพราะ `cargo` ออกแบบมาให้ทำงานกับเวอร์ชันที่ปล่อยมาด้วยกันเท่านั้น และบางครั้งอาจเข้ากันไม่ได้กับเวอร์ชันต่าง ๆ
> แต่ถ้าคุณกำลังไบเซกต์การเปลี่ยนแปลงที่เกิดขึ้นไม่นาน คุณน่าจะใช้วิธีนี้ได้
