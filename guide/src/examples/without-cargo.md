# การรันโดยไม่ใช้ Cargo

การไบเซกต์ในบางกรณีไม่จำเป็นต้องพึ่งพา Cargo
คุณสามารถใช้ตัวเลือก `--without-cargo` เพื่อข้ามขั้นตอนการติดตั้ง cargo ได้ ซึ่งจะช่วยให้การไบเซกต์รวดเร็วขึ้น เนื่องจากไม่ต้องเสียเวลาดาวน์โหลด cargo และลดภาระ (overhead) จากการรัน cargo
คุณจำเป็นต้องใช้งานตัวเลือกนี้ควบคู่กับ `--script` เสมอ เนื่องจากโดยปกติ `cargo-bisect-rustc` จะสันนิษฐานว่าโปรเจกต์ต้องใช้ Cargo

ตัวอย่างเช่น การสั่งรันคำสั่ง `rustc` โดยตรงอย่างง่าย:

```sh
cargo-bisect-rustc --start=2022-11-01 --end=2022-11-20 --without-cargo --script=rustc -- foo.rs
```

> **หมายเหตุ**: คุณสามารถใช้ตัวเลือก `--without-cargo` กับโปรเจกต์ Cargo ได้เช่นกัน
> โดย Rustup จะสลับไปเรียกใช้ `cargo` จากทูลเชน nightly, beta หรือ stable ที่คุณติดตั้งไว้ในเครื่องแทน
> อย่างไรก็ตาม ไม่แนะนำให้ใช้วิธีนี้ เนื่องจาก `cargo` ถูกออกแบบมาให้ทำงานคู่กับคอมไพเลอร์เวอร์ชันที่ปล่อยมาด้วยกันเท่านั้น และบางครั้งอาจเกิดปัญหาความไม่เข้ากันได้ระหว่างเวอร์ชันต่างๆ
> แต่หากคุณกำลังไบเซกต์การเปลี่ยนแปลงที่เพิ่งเกิดขึ้นไม่นานนี้ ก็มักจะพออนุโลมให้ใช้วิธีนี้ได้โดยไม่พบปัญหา
