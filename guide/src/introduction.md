# บทนำ

เครื่องมือ [`cargo-bisect-rustc`] ช่วยให้คุณค้นหาจุดที่พฤติกรรมของ rustc เกิดการถดถอย (regression) ได้อย่างง่ายดาย โดยจะดาวน์โหลดอาร์ติแฟกต์ของ rustc มาทดสอบกับโปรเจกต์ของคุณโดยอัตโนมัติจนกว่าจะพบจุดที่เกิดปัญหา

บท [การติดตั้ง](installation.md) จะแนะนำวิธีการติดตั้ง `cargo-bisect-rustc`
หากต้องการเริ่มต้นใช้งานอย่างรวดเร็ว สามารถดูได้ที่บท [บทช่วยสอน](tutorial.md)
หรือจะเริ่มอ่านจากบท [การใช้งานพื้นฐาน](usage.md) เพื่อทำความเข้าใจหลักการทำงานของ `cargo-bisect-rustc` ก็ได้เช่นกัน

[`cargo-bisect-rustc`]: https://github.com/rust-lang/cargo-bisect-rustc
