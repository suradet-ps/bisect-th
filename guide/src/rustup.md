# ทูลเชนของ Rustup

`cargo-bisect-rustc` ใช้ประโยชน์จากฟีเจอร์ [ทูลเชนของ rustup] ในการติดตั้งและสลับเลือกเวอร์ชัน `rustc` ที่ถูกต้องขึ้นมาทำงาน
โดยหลักการคือเครื่องมือจะสั่งรันคำสั่งทำนองว่า `cargo +bisector-nightly-2023-03-18-x86_64-unknown-linux-gnu build` โดยอาศัย [ตัวย่อการโอเวอร์ไรด์ทูลเชน] ของ rustup เพื่อสั่งรันทูลเชนเฉพาะที่ดาวน์โหลดมา
กระบวนการนี้จะกำหนดค่าตัวแปรสภาพแวดล้อม `RUSTUP_TOOLCHAIN` ให้เป็นชื่อของทูลเชนนั้น ซึ่งช่วยรับประกันว่าการเรียกใช้คำสั่ง `rustc` ทุกครั้งจะชี้ไปยังทูลเชนที่ถูกต้องเสมอ

โดยค่าเริ่มต้น `cargo-bisect-rustc` จะลบทูลเชนทิ้งทันทีเมื่อทดสอบเสร็จสิ้นในแต่ละรอบ
แต่คุณสามารถใช้ตัวเลือก `--preserve` เพื่อสั่งให้เก็บรักษาทูลเชนเหล่านั้นไว้ใช้งานหรือดีบักด้วยตนเองต่อได้
ดูรายละเอียดเพิ่มเติมได้ที่ตัวอย่าง [การรักษาทูลเชนไว้]

เมื่อใช้งานร่วมกับตัวเลือก `--script` ภายในสคริปต์คุณเพียงแค่เรียกใช้คำสั่ง `cargo` หรือ `rustc` ตามปกติ โดยปล่อยให้ตัวแปรสภาพแวดล้อม `RUSTUP_TOOLCHAIN` ทำหน้าที่เลือกทูลเชนที่ถูกต้องให้โดยอัตโนมัติ
